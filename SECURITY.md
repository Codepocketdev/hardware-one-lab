# Security

This is a lab project. Do not use it for real funds or a real Nostr identity.

- Use a spare device, a throwaway seed and throwaway Nostr identities.
- Never share or commit seed words, ~/.nostr_bridge.json or any key material.
- No firmware binaries are published here. Build your own.

Report problems in this repo by opening a GitHub issue that contains no secrets.
Report vulnerabilities in upstream Trezor firmware to security@satoshilabs.com.
